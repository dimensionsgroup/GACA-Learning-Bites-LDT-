# GACA Learning Bites · Leadership Development Program

Post-programme learning bites for the GACA Leadership Development Program (برنامج التطوير القيادي). One bite per two-day workshop, per track. Each bite is a 15-minute branching conversation in Arabic with one recurring character per track: the learner moves through the four stages of a leadership model, every reply changes the character's trust (shown on a four-state avatar), and the session ends with the hidden story, two possible futures, an evaluation matrix, a decision review and two reflection questions.

Every bite opens on a minimal dark editorial cover (programme masthead, track, workshop, title, illustration and one line in the character's voice) with a pulsing button into the session. The cover shows on every visit; the next page sets out the story, goal and four stages before the simulation starts; progress is kept and resumed from there.

## Running

- **Online:** with GitHub Pages enabled (Settings > Pages > Deploy from a branch > `main` / root), each bite lives at `https://<owner>.github.io/<repo>/<folder>/`.
- **Offline:** open any `index.html` in a browser. Each page is self-contained: fonts, logo and avatars are embedded.

## Notes

- «حالات …» in the footer reopens the four-mood guide mid-session and returns to the same decision.
- Avatar SVGs for slides are in `avatars/`.

## Privacy

Progress and reflection answers are saved only in the learner's own browser (localStorage). Nothing is sent anywhere.

## About the evaluation

The matrix is formative and for reflection only. It has not been validated and does not measure ability or personality. The two futures are common patterns, not predictions.
